How it works

1
Configure queries
Write X advanced-search queries targeting job keywords, hashtags, and handles of known recruiters.
2
Scrape & parse
The scraper hits X Search API (or the companion Python script) to collect tweets, then AI extracts role, company, and salary.
3
Review & export
Filter by role, location, and seniority. Export to CSV or push leads directly into the Leadflow pipeline.
The backend Python scraper (scrape_x_jobs.py) requires a X API v2 Bearer Token set as X_BEARER_TOKEN env var. This demo uses simulated data.
